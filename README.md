## Professional Overview

AI/ML engineer specializing in deep learning, natural language processing and large language models. At **GlobalSOC.ai** I build the AI layer behind enterprise products in cyber insurance, sales automation and CRM: machine-learning risk scoring, multi-agent LLM pipelines and AI-assisted workflows inside multi-tenant SaaS platforms.

My independent work focuses on **local-first, explainable AI**: on-device speech assistants, real-time speech translation for Indian languages, an open-source security operations platform with an evidence-grounded AI analyst, and retrieval-augmented systems for legal text.

I care about AI that holds up in production: models that run on your own hardware, scores that explain themselves, and safety checks that don't depend on the LLM behaving.
